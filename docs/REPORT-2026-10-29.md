## 3. 보안 규칙 변경 (게시 필요)

게시된 버전(cad3afc) 대비 바뀐 점입니다. 에뮬레이터 테스트 **108개 통과**(수강 등록 9 · 보관된 반 25 · 소통 16 · 데이터 구조 24 · 학생 동선·학습 목표 24 · 옛 화면 호환 10).

**Firestore**
1. 읽기는 `enrolled(cid)`(수강 중 등록, 반 보관 여부와 무관), 쓰기는 `member(cid)`(운영 중인 반만) → 보관된 반은 읽기 전용.
2. 질문: 상태 필드 허용, 학생은 자기 질문의 '답변 대기로 되돌리기'와 확인 시각만 변경, `weekId`·`context`(assignment·quiz) 허용.
3. 과제 제출: 회차 번호 검증(건너뛰기 거부), 처음 제출 시각 변경 거부, 학생의 피드백 필드 변경 거부, 제출 이력 `revisions`는 만들기만 가능, 확인 시각은 서버 시각만.
4. 퀴즈: `quizVersions`는 강사 전용, 첫 응시 보존, 응시 기록의 `mode:'wrongOnly'`는 요약 문서 없이 저장 가능(문항 수 ≤ 전체).
5. 수강 기간 기록 `events`: 강사만 읽기, 학생은 입장 때 'joined' 하나만(등록과 같은 일괄 쓰기), 수정 불가.
6. 다음 학습 목표 `studentGoals`: 강사만 쓰기(200자), 그 학생만 읽기.

**Storage**
1. 강의 영상: 운영 중인 반의 수강생(`openMember`) 또는 강사만 재생 → 보관된 반에서는 영상만 차단.
2. 영상 업로드 한도 2GB → 10GB(D9). 2026-10-29 확인: 10GB 그대로 둡니다.
3. 과제 음성 업로드는 운영 중인 반에서만.
4. Storage 규칙이 한 번에 읽을 수 있는 Firestore 문서는 2개까지라, 그 안에 들어가도록 판정 순서를 맞췄습니다. **에뮬레이터는 이 한도를 검사하지 않으므로, 게시 후 실제 기기에서 영상 재생을 꼭 확인해 주세요.**

## 8. 추가 기능 (2026-10-29 요청): 복습 수업 영상 · 공지사항

### 8-1. 복습 수업 영상
- **강사:** 차시별 학습자료 → '수업 후 · 복습' 탭 맨 위에 '🎬 수업 영상'(공개 ON/OFF). 예습 영상과 같은 방식입니다. 직접 올리면 10GB까지, 유튜브 '일부 공개' 링크도 됩니다. 켜 놓고 영상이 하나도 없으면 저장하지 않고 안내합니다. 차시의 공개 요약에도 '수업 영상 ✓/✕'가 보입니다.
- **학생:** 영상이 있는 차시에서는 복습 탭이 **'수업 영상 | 복습 퀴즈' 두 화면**으로 나뉩니다. 처음에는 수업 영상 화면을 보여 주고, 학생이 고른 화면은 다시 와도 유지합니다. 홈 '이번 차시 할 일'에 '수업 영상' 줄을 두어 영상 화면으로 바로 갈 수 있습니다. 영상이 없는 차시는 지금처럼 퀴즈만 보입니다.
- **보관된 반:** 영상 대신 "이 차시의 수업 영상 N개는 수강 기간에만 볼 수 있어요"라는 안내만 보여 주고, 영상 주소도 요청하지 않습니다. Storage 규칙에서도 차단합니다.
- **데이터:** 차시 문서의 `recap{enabled, videos[]}`, 직접 올린 파일은 Storage `classes/{반}/recaps/{차시}/video/`. 차시·반을 영구 삭제하면 이 파일도 함께 정리합니다.

### 8-2. 공지사항
- **강사:** 사이드바에 '공지사항'을 추가했습니다.
  - 공지를 올리기·수정·상단 고정·삭제할 수 있습니다.
  - 공지마다 '읽음 n/m명'과 '안 읽은 학생' 이름이 보입니다.
  - 작성 창은 바깥을 눌러도 닫히지 않고, 쓰던 내용이 있으면 닫기 전에 묻습니다.
- **학생:**
  - 홈 맨 위에 상단 고정 공지와 새 공지가 최대 3개 보입니다.
  - 하단 메뉴 '홈'에 새 공지 수가 배지로 붙습니다.
  - '공지사항' 화면은 고정 공지 → 최근 공지 순입니다. 본문의 http 주소는 새 탭 링크가 됩니다.
  - 공지 화면을 열면 확인 시각을 남겨, 새 공지 표시와 배지가 사라집니다. 보는 동안에는 새 공지 표시를 남겨 둡니다.
- **보관된 반:** 지난 반 안내 줄의 '공지 보기'로 읽기만 합니다. 확인 시각은 쓰지 않습니다.
- **'읽음'의 뜻:** 공지를 올린 뒤 학생이 공지 화면을 연 경우입니다. 홈 카드에서 제목만 본 것은 읽음으로 세지 않습니다. 지금 수강 중인 학생만 셉니다.
- **한계:** 문자·푸시·메일 알림은 보내지 않습니다. 보내려면 서버 기능(Cloud Functions 등)이 필요하고 요금제 조건은 확인이 필요합니다. 휴강처럼 급한 공지는 단체 대화방에도 함께 알려 주세요.
- **데이터:** `classes/{반}/notices/{공지}`(제목 1~100자, 내용 5,000자 이하, 상단 고정), `classes/{반}/noticeReads/{학생}`(확인 시각 하나).

### 8-3. 보안 규칙 (다시 게시 필요)
- **Firestore:** `notices`(강사만 쓰기, 이 반 수강생 읽기), `noticeReads`(학생 본인만, 서버 시각만, 운영 중인 반에서만 쓰기, 강사 읽기).
- **Storage:** `recaps/{차시}/video/`(예습 영상과 같은 조건).
