# [11] 학생 상세(학습 프로파일) · 수강생 관리 정리 (P3-01, P3-02)

> 먼저 `docs/prompts/00-common.md`를 읽고 따르세요.
> 선행 배치: 06(제출 이력·퀴즈 버전·수강 기간), 09(진행표·`computeDashboard`). 없으면 가능한 범위로 만들고 빠진 부분을 보고합니다.

## 1. 목표

출결·과제·복습·질문·강사 메모가 다섯 메뉴에 흩어져 있어, 학생 한 명을 이해하려면 메뉴를 여러 번 옮겨 다녀야 합니다.
**학생 한 명 기준으로 모아 보는 화면**을 만들고, 가장 복잡한 화면인 수강생 관리 표를 단순하게 만듭니다.

## 2. 현재 문제 (cd043b9)

- 수강생 관리 표(`showStudents`, `admin.html:1209`): 7개 열, 한 행에 버튼 6개, 최소 너비 880px. 모바일에서는 가로 스크롤 끝에 조작 버튼이 있습니다.
- 강사 메모가 있는지 표에서 보이지 않습니다(버튼을 눌러야 확인).
- 학생별 정보 조회 경로: 출석현황 모달, 메모 모달, 과제·복습 관리(차시마다), 질문함(따로)

## 3. 요구사항

### 3-1. 학생 상세 화면

**여는 곳:** 수강생 관리 행 클릭, 대시보드 진행표의 학생 이름, 과제·복습 관리와 질문함의 학생 이름
**형태:** PC는 오른쪽 패널(목록 유지), 모바일은 전체 화면 + [← 목록]

**구성 (위에서 아래로)**
1. **기본 정보:** 이름·별명, 이메일, 반, 등록일, 수강 상태, 수강 기간 이력(이동·중지)
2. **최근 4~8차시 요약:** 진행표와 같은 기호(출결·과제·복습)
3. **과제:** 차시별 제출 회차 수, 최근 피드백, [제출 비교](배치 06 화면으로 이동)
4. **복습:** 차시별 첫 응시 → 최근 응시 점수. 작은 꺾은선이나 표로 표시하고 n을 함께 씁니다. legacy·버전 미상 기록은 구분합니다.
5. **질문:** 최근 질문과 상태(답변 대기 / 완료)
6. **강사 메모 🔒** — `강사만 볼 수 있어요` 표시, 다른 배경색으로 학생 공개 정보와 확실히 구분, 그 자리에서 편집
7. **(선택) 다음 학습 목표:** 학생에게 **공개되는** 한 줄 목표. 예: `다음 과제에서는 연결 표현(pero, porque)을 2개 써 보기`
   - 강사 메모와 **저장 위치를 분리**합니다. 예: `classes/{cid}/studentGoals/{uid}` (해당 학생 + 강사만 읽기)
   - 학생 홈(배치 10)에 표시합니다.
   - 보안 규칙 수정안을 냅니다.

**데이터 로딩:** 상세를 열 때 필요한 것만 조회합니다(지연 로딩). 차시가 많으면 최근 8차시만 먼저 보여 주고 [더 보기]를 둡니다.

### 3-2. 수강생 관리 표 단순화

- **열:** 이름(별명·실명) · 상태 · 최근 출결(기호 4칸) · 최근 과제(기호 4칸) · 메모 아이콘 · `⋯`
- **`⋯` 메뉴로 옮길 동작:** 출석현황, 메모, 실명 수정, 반 이동, 수강 중지/재등록
  - 키보드로 열고 닫을 수 있어야 합니다(Enter/Space로 열기, Esc로 닫기, 화살표로 이동).
- **메모 아이콘:** `teacherNotes`를 반 단위로 한 번 조회해 메모가 있는 학생에게 표시합니다.
- **필터:** 전체 / 수강 중 / 수강 중지 / 반 이동 (배치 04에서 추가한 항목 유지)
- **'활성 반 중복' 경고**(배치 04) 유지
- **모바일(640px 이하):** 표 대신 카드형 목록(이름·상태·최근 기호 + `⋯`)
