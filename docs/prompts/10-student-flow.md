# [10] 학생 동선 · 새 소식 알림 (P2-05 ~ P2-09)

> 먼저 `docs/prompts/00-common.md`를 읽고 따르세요.
> 관련 결정사항: **D6**(학생 메뉴 A안/B안), D3(마감 표시), D8(예습 의미).
> 선행 배치: 05(질문 필드, `reviewState`), 06(확인 시각 `studentSeenFeedbackAt`·`studentSeenAt`, 제출 이력, `submissionTiming`), 07(초안), 08(`sessionState`, 예습).

## 1. 목표

학생은 들어오자마자 **이번 차시에 할 일과 새로 받은 피드백·답변**을 봅니다. 강사는 사이드바에서 **처리할 일이 있는 메뉴**를 바로 알 수 있습니다.

## 2. 현재 문제 (cd043b9)

- 첫 화면이 '과제' 탭입니다. 이미 제출했어도 편집 폼이 먼저 보이고, 새 피드백은 아래로 내려야 보입니다(`renderAssignment`, `index.html:526`).
- 하단 탭 6개(`NAV`, `index.html:434`): 작은 화면에서 라벨이 9~11px까지 줄어듭니다. 아이콘은 이모지와 기호가 섞여 있습니다.
- 복습 화면에 들어가면 이미 푼 학생도 곧바로 1번 문항부터 시작합니다(`renderQuiz`, `index.html:565`).
- 새 피드백·새 답변을 알려 주는 표시가 학생·강사 모두에게 없습니다.

## 3. 요구사항

### 3-1. 메뉴 구성 (D6)

**B안 (권장, 실제 데이터 없을 때): `홈 · 과제 · 복습 · 질문 · 내 정보` (5개)**
- **홈 (기본 화면)**
  1. 다음 수업 카드: `3차시 · 10월 30일 (목) · 내일`. 수업 시각 필드는 없으므로 날짜만 표시합니다.
  2. 이번 차시 할 일 체크리스트
     - 예습: `자료 보기` (확인 기능은 배치 13 P4-12)
     - 과제: `미제출 · 마감 D-2` / `제출함` / `피드백 도착` / `재검토 중` / `마감 지남`
     - 복습: `미응시` / `첫 점수 67%` / `다시 풀기 가능`
  3. 새 소식: `새 피드백 1개 (3차시 과제)`, `질문 답변 도착 1개` → 누르면 해당 화면으로 이동
  4. 예습 자료 미리보기 카드 (D8 기준, 다가오는 차시)
  5. 출석 요약: `출석 3 / 4차시` → 상세는 내 정보
- '다음차시' 탭은 없애고 예습은 홈과 각 차시 화면으로 옮깁니다.
- '우리 반'은 내 정보 안의 '우리 반 친구들' 카드로 옮깁니다.

**A안 (실제 데이터가 있을 때): `과제 · 복습 · 다음차시(예습) · 질문 · 내 정보` (5개)**
- '우리 반'만 내 정보로 옮깁니다.
- 과제 화면 상단에 한 줄 요약 바를 둡니다: `이번 수업: 3차시 · 과제 미제출 · 복습 완료 · 새 피드백 1개`

**하단 탭 공통**
- 아이콘은 강사 사이드바와 같은 선 스타일의 SVG를 씁니다.
- 라벨은 12px 이상으로 하고, 370px 이하 화면에서도 줄이지 않습니다(아이콘 크기로 조정).
- 활성 탭은 색 + 굵기 + 상단 표시선으로 구분합니다(색에만 의존하지 않음).
- 배지는 점 또는 숫자로 표시하고 `aria-label`을 붙입니다. 예: `과제, 새 피드백 1개`

### 3-2. 과제 화면

- **제출 기록이 있으면**
  1. '제출한 답안' 카드를 먼저 보여 줍니다: 텍스트 요약, 음성(길이 표시), 제출 시각, 회차
  2. 피드백을 그 아래에 표시합니다. 최신 피드백이 맨 위이고, 회차를 표시합니다.
  3. [수정해서 다시 제출] 버튼을 누르면 편집 폼이 열립니다(배치 07의 초안 복원 포함).
- 피드백 카드마다 [이 피드백에 질문하기]를 둡니다.
  - 누르면 질문 작성 폼이 열리고, 제목에 `[3차시 과제] ` 접두어가 붙습니다.
  - 질문 문서에 `weekId`, `context:'assignment'`를 저장하고, 강사 질문함에 차시를 표시합니다.
  - 보안 규칙의 질문 생성 허용 필드에 이 두 필드를 추가합니다.
- 마감 표시: `마감 10월 30일 (목) 오후 11:59 · D-1` / `마감이 지났어요 · 늦은 제출로 기록돼요` (D3)

### 3-3. 복습 화면

- **응시 기록이 있으면** 결과 카드를 먼저 보여 줍니다: 첫 점수, 최근 점수, 틀린 문항과 해설
- 버튼: [틀린 문제만 다시 풀기] [전체 다시 풀기]
  - **틀린 문제만** 응시는 `attempts`에 `mode:'wrongOnly'`로 저장합니다. `quizResults`의 `score`·`total`·`firstAttempt`는 바꾸지 않습니다. 부분 점수는 전체 점수와 비교할 수 없기 때문입니다.
  - 결과 화면에서는 '지난번 틀린 n문항 중 m문항 정답'처럼 보여 줍니다.
- 반복 횟수를 성취처럼 강조하지 말고, 이번에 새로 맞힌 문항을 짧게 알려 줍니다. 예: `지난번에 틀린 'Buenas noches는 무슨 뜻인가요?'를 이번에 맞혔어요`. 학습 목표 태그(배치 13 P4-02)가 생기면 태그 이름으로 바꿉니다. 예: `'estar + 형용사' 문항을 맞혔어요`

### 3-4. 새 소식 배지

| 위치 | 계산 |
|---|---|
| 학생 과제·복습 탭(또는 홈) | 피드백 시각 > `studentSeenFeedbackAt` |
| 학생 질문 탭 | `lastSenderRole === 'admin'` 이고 `lastMessageAt` > `studentSeenAt` |
| 강사 사이드바 '질문함' | 현재 반의 `needsReply(q)` 개수 |
| 강사 사이드바 '과제·복습 관리' | 현재 반에서 최근 완료·진행 중 차시의 '피드백 대기 + 재검토 대기' 개수 |

- 해당 화면을 보면 배지가 사라집니다(확인 시각 갱신, 배치 06).
- 학생 배지 계산에 필요한 구독은 이미 열려 있는 구독을 재사용하고, 새로 여는 구독 수를 보고합니다.
- 강사 배지는 대시보드(배치 09)의 `computeDashboard` 결과나 같은 쿼리를 재사용합니다.

### 3-5. 질문 화면

- 질문 목록에 차시 표시(`weekId`가 있을 때), 정렬은 최근 대화순(배치 05)
- 질문 작성 폼에 차시 선택(선택 사항)을 추가합니다.
